## Compra de criptomoedas via Binance

O programa `main.go` demonstra como realizar uma ordem de compra de `BTCUSDT` usando a API da Binance. Defina as variáveis `BINANCE_API_KEY` e `BINANCE_SECRET_KEY` antes de executar:

```bash
export BINANCE_API_KEY=seu_api_key
export BINANCE_SECRET_KEY=seu_secret_key

go run main.go
```
